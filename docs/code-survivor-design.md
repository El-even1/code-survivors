## 1. 意图与核心卖点

**一句话**：一款“只动手指、不动脑子也能打，但动脑子能打得更爽”的幸存者类游戏——把“选技能”升级为“搭管线”。

玩家不直接选择被动技能，而是**拖拽节点搭建“触发→条件→动作→修饰”的可视化管线**，管线在战斗中自动执行并造成伤害。**战斗中只能切换 2–3 槽位管线预设**，暂停或安全区内可编辑管线内容；战斗外通过 **芯片树** 解锁新节点类型，解锁更多“可以搭的东西”。

**核心爽点**：屏幕上红方块海被白圈/AoE/投射物清空，配合跳动的合并数字（×N）；以及“我搭出来的管线在跑，我切换槽位，管线立刻换了”的即时反馈。

---

## 2. 品类定位与差异化

| 维度 | 传统幸存者 | 本设计 |
|------|-----------|--------|
| 技能获取 | 升级三选一，随机池 | 拾取/合成“指令块”，搭建可视化管线 |
| 技能构建 | 被动叠加数值 | 可视化节点图，拖拽连线，暂停/安全区编辑 |
| 核心爽点 | 数字变大 | “我搭出来的组合在跑” + 暂停调整快感 |
| 成长维度 | 单一数值膨胀 | 局内管线 + 元游戏芯片树 + 叙事协议解密（三层） |
| 关卡结构 | 单图生存 15–30 min | 非线性扇区制，玩家选顺序，不同顺序产出不同指令块倾向 |
| 目标平台 | PC/主机 | 微信小游戏优先（4MB 主包、分包、GC 友好、竖屏交互） |

### 不做的事（反目标）
- ❌ 不做 6 槽位同时生效（武器/管线同时跑）—— 不支持多槽位并行，只支持切换。
- ❌ 不做独立的“宝石联动”体系（主动宝石+辅助宝石）—— 合并进四元组，动作可挂载辅助修饰符。
- ❌ 不做 v1.0 的 UGC 商店/社区—— 微信小游戏审核风险高，v1.5 官方赛季投稿制再考虑。
- ❌ 不做动作瞄准/躲避—— 保留幸存者一手操作、自动攻击的核心循环。

## 3. 核心系统设计

### 3.1 管线：触发-条件-动作-修饰（四元组）

```
[触发器] ──→ [条件/过滤] ──→ [动作/效果] ──→ [修饰符]
   │             │              │              │
 最近敌人      生命>50%       发射投射物      穿透+分裂
 血量最低      距离<300       召唤领域        持续时间+范围
 受到攻击      携带Buff       施加状态        概率触发/冷却
 定时器        随机概率       修改属性        连锁/延迟
```

- **指令块 = 物品**。击杀精英/宝箱/商店掉落，品质：白/绿/蓝/紫/金。
- **搭建上限**：初始 3 槽位，升级/道具可扩展（局内固定，不随战斗改变）。
- **管线编辑**：仅在**暂停菜单**或**安全区**中进行。战斗中**不可拖拽节点、不可换指令块、不可调参数**，只能切换槽位。
- **暂停编辑器**：手机点暂停 / PC 按 Esc，进入简易编辑器，只能修改当前激活槽位的管线；安全区内提供完整编辑器，可拖拽节点、合成指令块、调参数。

### 3.2 槽位切换（2–3 槽位）

- 初始 **3 槽位管线预设**（可在设置/芯片树中减至 2 槽位作为简化模式）。
- 槽位间**不同时生效**，切换时当前管线暂停，另一槽位管线接管。
- 切换时机：**安全区内随意切换**；战斗中可随时切槽位，切换后新槽位管线立刻接管输出。**战斗中仅支持切槽位，不支持修改管线内容。**
- 每个槽位独立升级、独立指令块，共享玩家属性（血量、移速、磁吸等）。

### 3.3 修饰符标签共鸣（Magicraft 式，简化版）

- 指令块带标签：`火/冰/电/毒/物理/光/暗` 等。
- 管线内**相邻且标签相同**的修饰符/动作，触发“共鸣”，该环节效果 +15%（伤害/范围/持续时间任选其一，由修饰符定义）。
- 纯奖励，不强制套路；玩家可全杂交也可专精。

### 3.4 宝石联动（合并进四元组）

- 不另建独立宝石体系。
- **动作节点**可挂载 0–1 个“辅助修饰符”：穿透、分裂、链弹、持续伤害、范围扩大、冷却缩减。
- 辅助修饰符本身也是可收集的指令块，品质越高数值越强。

## 4. 成长体系（三层）

| 层级 | 名称 | 作用 | 持续时间 |
|------|------|------|----------|
| 战术层 | 局内管线搭建 + 指令块合成 + 临时词缀 | 每把 15 min，核心决策 | 单局 |
| 策略层 | 芯片树（元游戏） | 解锁新指令块类型/修饰符/触发器 | 永久 |
| 叙事层 | 协议解密 | 每通关一次解锁世界设定/角色档案/隐藏关卡 | 长线 |

### 芯片树
- 节点类型：触发器分类 / 动作分类 / 修饰符分类 / 槽位扩展 / 基础属性。
- 每通关一个扇区获得 1–2 个“芯片点”，投入解锁。
- 解锁后，局内掉落池中会出现对应类型的指令块。

## 5. 关卡结构：非线性扇区制

```
入口扇区（教学/安全区）
   │
   ├─→ 扇区 A：数据洪流（高频小怪，考验 AoE 管线）
   ├─→ 扇区 B：防火墙堡垒（精英少、血厚，考验爆发/穿透）
   ├─→ 扇区 C：逻辑迷宫（地形机关，考验位移/召唤）
   └─→ 核心扇区：最终协议（Boss 战，多阶段，需切换管线预设）
```

- 单局 3–4 个扇区，每扇区 3–5 min，中间有**安全区**可整理管线、合成指令块、选协议增益。
- 扇区顺序玩家自选，不同顺序产出不同指令块倾向（二周目动力）。
- Boss 战需切换 2–3 槽位预设应对多阶段机制。

## 6. 怪物与威胁设计（针对“管线”的反制）

| 怪物 | 反制逻辑 | 玩家应对 |
|------|----------|----------|
| 干扰器 | 周期性清空玩家所有修饰符 | 带“免疫清除”触发器，或做无修饰符基础管线 |
| 镜像怪 | 复制玩家当前主攻管线并反向使用 | 热切换到备用槽位管线 |
| 协议守卫 | 仅对特定触发器类型免疫 | 多准备不同触发器的管线预设 |
| 数据洪流 | 极高频小怪，单体伤害低 | 必须搭建大范围/穿透/链弹管线 |

## 7. 平台与多平台发布策略

### 7.1 平台分布

| 市场 | 平台 | 优先级 | 备注 |
|------|------|--------|------|
| 海外 | Google Play | P0 | 主渠道 |
| 海外 | Apple App Store | P0 | 主渠道 |
| 海外 | Web H5 | P1 | 浏览器直玩，低门槛获客 |
| 国内 | TapTap | P0 | 国内主渠道，独立国内版 |
| 国内 | 微信小程序 | P0 | 国内主渠道，独立国内版 |
| 国内 | 抖音小游戏 | P1 | 国内流量补充 |
| 后续 | Steam | P2 | 成绩好后考虑，PC 付费版 |

### 7.2 国内版与海外版分离

- **国内版**：TapTap + 微信小程序 + 抖音小游戏，走国内版号/备案流程，广告 SDK 和支付接口使用国内供应商。
- **海外版**：Google Play + App Store + Web H5，海外账号体系、海外广告（AdMob/Unity Ads 等）和海外支付。
- 两版代码共用核心逻辑，仅渠道层、广告层、登录层分离编译。

### 7.3 技术约束（各平台共通）

| 约束 | 应对 |
|------|------|
| 4MB 主包（微信小游戏） | 核心逻辑 < 200KB（TS 编译后）；指令块定义用 JSON 远程下发；美术用矢量/程序化生成 |
| GC 压力 | 对象池复用所有指令块实例、投射物、粒子；管线执行用定点数/整数运算 |
| 启动速度 | 首包只含引擎运行时 + 编辑器核心 + 入口扇区资源；其余分包加载 |
| 审核周期 | 先做纯单机版过审，热更下发扇区/指令块/协议内容 |
| 竖屏交互 | 左摇杆移动，右侧留白；战斗中仅显示槽位切换按钮；编辑仅在暂停/安全区进行 |
| Web H5 | 无需安装即玩，做获客入口；付费与内购走 Web 支付 |
